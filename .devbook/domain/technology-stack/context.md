# Technology Stack

```meta
status: draft
index: root
type: context
```

Technology Stack maintains authoritative definitions of supported technologies,
tools, frameworks, and their version requirements across the portfolio. It answers
"what tools do we use and what versions should we be on?". It enforces approved
baselines, tracks adoption, and manages deprecation.

It is the authoritative baseline owner. It provides baselines consumed by
[Dev PC Management](../dev-pc-management/domain.md#machine-registry) and
[Repository Management](../repository-management/domain.md#repository-registry),
and both report adoption back.

Outside it: scanning what a repository or a machine actually has, which
Repository Management and Dev PC Management answer and report back.
