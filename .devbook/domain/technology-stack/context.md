# Technology Stack

```meta
index: root
type: context
```

Technology Stack maintains authoritative definitions of the supported technologies,
tools and frameworks, and of their version requirements across the portfolio. It answers
"what tools do we use and what versions should we be on?". It enforces approved
baselines, tracks adoption, and manages deprecation.

It owns the baselines. [Dev PC Management](../dev-pc-management/domain.md#machine-registry) and
[Repository Management](../repository-management/domain.md#repository-registry)
consume them and report adoption back.

Outside it: scanning what a repository or a machine actually has, which
Repository Management and Dev PC Management answer and report back.
