# Brain

```meta
index: root
```

Your own notes, kept as Markdown in this folder and read by Backlog as your
Brain. It belongs to you rather than to any repository, so notes about several
repositories live together here.

`CONVENTIONS.md` beside this file says how the folder is laid out: which areas
it has, in which order Backlog shows them, and the fields a note may carry. Edit
it to make the Brain your own.

Backlog never writes its search database into this folder. It builds that in
its own storage on each machine, so a synced folder only ever carries your
Markdown.
